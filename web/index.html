🖥 客户端远程导入（配对码）

    
在装有 AutoClaw 的 Windows 电脑运行 autoclaw-client-windows-amd64.exe，输入服务器地址与下方配对码（10 分钟有效）：

    
------

    

    
# 读本机已登录态导入
autoclaw-client-windows-amd64.exe -server http://<本服务器>:8317 -code <配对码> -mode import
# 重置设备+等手动登录后导入（设备拉黑自救）
autoclaw-client-windows-amd64.exe -server http://<本服务器>:8317 -code <配对码> -mode reset -loop

    

      ⬇ 下载客户端（已内置服务器地址）
